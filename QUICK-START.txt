  Quick Start Guide

✅ WHAT YOU HAVE:

Your complete Liver Health Connect website is ready with:

├── index.html                 ← Homepage (exact replica)
├── styles.css                 ← All styling (extracted for reusability)
├── navbar.html                ← Navigation component (auto-injected)
├── footer.html                ← Footer component (auto-injected)
├── js/components.js           ← Smart loader for navbar & footer
├── pages/
│   └── liver-health-basics.html ← Sample subpage (use as template)
├── assets/images/
│   └── LHC_logo_transparent.png ← Your logo
└── README.md                  ← Full documentation

🎯 NEXT STEPS (Do This Now):

1. CREATE A GITHUB REPOSITORY
   ✓ Go to github.com/new
   ✓ Name it: liver-health-connect (or username.github.io)
   ✓ Set to Public
   ✓ Click "Create Repository"

2. UPLOAD YOUR FILES
   OPTION A - Using Command Line (Recommended):
   $ cd /path/to/your/files
   $ git init
   $ git add .
   $ git commit -m "Initial commit: Liver Health Connect"
   $ git remote add origin https://github.com/YOUR_USERNAME/liver-health-connect.git
   $ git branch -M main
   $ git push -u origin main

   OPTION B - Upload via GitHub Web:
   ✓ Click "uploading an existing file"
   ✓ Drag and drop all files from this folder
   ✓ Add commit message "Initial commit"

3. ENABLE GITHUB PAGES
   ✓ Go to your repository → Settings
   ✓ Click "Pages" in the sidebar
   ✓ Under "Build and deployment":
     - Branch: select "main"
     - Folder: select "/root" (or "/")
   ✓ Click Save
   ✓ Wait 1-2 minutes for deployment

4. YOUR SITE GOES LIVE!
   Your site will be available at:
   - https://username.github.io/liver-health-connect/
   (or https://username.github.io/ if using username.github.io repo)

🎨 CUSTOMIZATION:

The GENIUS of this setup is that you only need to edit 3 files:

1. navbar.html  → Change menu items, add links, update logo
2. footer.html  → Change footer links, social media, copyright
3. styles.css   → Change colors, fonts, spacing

Changes to these files appear on EVERY page automatically!

📝 CREATE NEW SUBPAGES:

1. Copy pages/liver-health-basics.html to pages/your-new-page.html
2. Edit the <title> and <h1>
3. Add your content
4. The navbar and footer load automatically!

That's it! The navbar and footer are INJECTED automatically.

🔧 IMPORTANT DETAILS:

✓ All files must stay in their folders
✓ Don't rename the core files (navbar.html, footer.html, styles.css, js/components.js)
✓ Always use paths like: /pages/page-name.html
✓ Test locally by opening index.html in your browser
✓ Hard refresh (Ctrl+Shift+R) if changes don't show

❓ TROUBLESHOOTING:

Navbar/Footer not showing?
→ Check browser console (F12) for errors
→ Verify files are in correct folders
→ Hard refresh (Ctrl+Shift+R)
→ Check internet connection (components load via fetch)

Images not showing?
→ Verify /assets/images/ folder exists
→ Check image paths in navbar.html
→ Hard refresh

Styles look wrong?
→ Ensure styles.css is linked in <head>
→ Check for missing files in DevTools Network tab
→ Hard refresh browser cache
