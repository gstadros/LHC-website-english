Liver Health Basics

Understanding your liver and how to keep it healthy

What You Need to Know

This page is a template for creating subpages. The navbar and footer are automatically injected from separate files, making it easy to maintain consistency across your entire website.

✨ How This Works

When you load this page, the JavaScript file /js/components.js automatically:

  • ✓ Fetches /navbar.html and injects it at the top
  • ✓ Fetches /footer.html and injects it at the bottom
  • ✓ Initializes all interactive features (hamburger menu, scroll animations, etc.)

Key Benefits

📝 Single Source of Truth

Update the navbar or footer once, and changes appear on every page automatically—no need to edit each file individually.

⚡ Easy Maintenance

Add new navigation links, change footer content, or update social media links in one place.

🎯 Consistent Experience

Every page has the same navigation and footer, creating a cohesive user experience across your entire site.

Creating New Subpages

To create a new subpage, simply:

  1. Copy this template to your /pages folder
  2. Change the <title> and page heading
  3. Add your unique content to the main section
  4. The navbar and footer will automatically load!

File Structure

your-repo/
├── index.html              # Homepage
├── styles.css              # All shared styles
├── navbar.html             # Navbar component (auto-injected)
├── footer.html             # Footer component (auto-injected)
├── js/
│   └── components.js       # Loads navbar and footer
├── assets/
